The icon set is 49 line icons drawn on a 24px grid for Moss & Mist. Every icon has a 2px stroke with round ends and round corners, so the strokes match the 2px control edges and the tight `radius-md` corners of the rest of the system. They are monochrome and take their colour from the text around them (`currentColor`). Nothing is filled except the dark half of `contrast` and the dots made by round line caps.

**Names:** `menu`, `close`, `arrow-left`, `arrow-right`, `chevron-left`, `chevron-right`, `chevron-down`, `chevron-up`, `check`, `plus`, `minus`, `search`, `home`, `grid`, `path`, `list`, `tool`, `contrast`, `info`, `warning`, `x-circle`, `check-circle`, `user`, `sliders`, `bell`, `pencil`, `trash`, `copy`, `external`, `download`, `calendar`, `clock`, `eye`, `star`, `file`, `inbox`, `rocket`, `code`, `bar-chart`, `mail`, `link`, `globe`, `more`, `sun`, `moon`, `sort`, `coffee`, `gamepad`, `film`.

**Sizes.** Use 16, 20 or 24 only. 16 sits inside chips, tags and compact buttons, 20 in standard buttons, inputs and nav rows, and 24 in bottom tabs, full-screen menu rows and empty states. The stroke is 2px at every size (`vector-effect: non-scaling-stroke`), so a 16px icon is bolder than a scaled-down 24px one on purpose, matching chip edges. Set the size with `mm-ico` (20px) or `mm-ico--16`, `mm-ico--20`, `mm-ico--24`.

**Colour.** Icons are `ink` by default, `ink-muted` when quiet, `green` when active or selected, and the status colour with its icon for status (`check-circle` green, `warning` marigold-text, `x-circle` error, `info` ink on `surface-muted`). An icon and its label always share one colour. Colour never carries meaning alone: pair it with the shape or a message.

**Accessibility.** A decorative icon next to a label gets `aria-hidden="true"` (the sprite is hidden already). An icon-only button needs an `aria-label` and the usual 48px target (36px compact), however small the icon is. Do not use an icon the user cannot read without a label for an action that is destructive, such as `trash`.

**Adding icons.** Draw on the 24px grid with a 3px safe margin (live area 3 to 21), 2px stroke, round caps and joins, and no more than one filled shape. Keep each icon recognisable at 16px. Name it for what it shows, not where it is used.
