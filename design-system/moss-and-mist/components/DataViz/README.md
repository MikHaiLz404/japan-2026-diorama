# DataViz

Series colours `data-1` to `data-5` (fixed order, never cycled) and the one-hue green ramp `data-seq-1` to `data-seq-6`. Pass the colours through the chart's own fill or stroke. Always add a legend for two or more series, direct labels at line ends, and a table view; `data-3` needs these most because its contrast is under 3:1 in light. See Data visualisation in the main README.
